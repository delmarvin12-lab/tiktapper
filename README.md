# TikTapper

Android auto-tapper for TikTok Live likes. A floating START/STOP panel plus a red ring you drag onto the live video; while running it taps where the ring is, with slightly varied timing and position.

## Get the APK (pick one)

**A. GitHub, no software needed**
1. Create a free GitHub account and a new repository.
2. Upload everything in this folder (keep the folder structure, including `.github`).
3. Open the **Actions** tab → **Build APK** → wait about 5 minutes.
4. Open the finished run → download **TikTapper-apk** → unzip → `app-debug.apk`.

**B. Android Studio**
Open this folder in Android Studio → Build → Build APK(s).

## Install and turn on
1. Copy `app-debug.apk` to your phone and install it (allow "Install unknown apps" when asked).
2. Android 13 and newer: Settings → Apps → TikTapper → ⋮ (top right) → **Allow restricted settings**.
3. Open TikTapper → **Open Accessibility settings** → TikTapper → turn on.

## Use
1. Open a TikTok Live.
2. Drag the red ring onto an empty part of the video, away from the chat, gift and share buttons.
3. Press **START**. Press **STOP** when done (it also stops by itself after the time you set).

Settings in the app: taps per second (1–10, default 5) and auto-stop time (1–60 minutes, default 10).

## Note
TikTok can flag automated tapping. Moderate speeds and shorter sessions lower the risk, but there is no guarantee. Use an account you can afford to have restricted.
